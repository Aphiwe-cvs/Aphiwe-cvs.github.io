## 1. Organisation Overview

* **Name:** Inkanyezi Events


* **Brief History:** A small event planning business named after the founder's daughter.


* **Mission & Vision Statement:** "To create memories with a nice event that has a lovely decor, like weddings, birthday parties and baby showers etc."


* **Target Audience:** General public seeking event planning and decor services.



---

## 2. Website Goals and Objectives

* **Goal:** Provide detailed service and package information while showcasing past events to build brand trust and drive event bookings.


* **Key Performance Indicators:** Site traffic, package inquiries, contact form submissions, and client portal registrations.



---

## 3. Proposed Website Structure & Features

The website consists of 5 core HTML pages:

* **Home Page (`index.html`):** Features a high-impact hero banner, an overview of core event services, and clear call-to-action sections.


* **Services Page (`services.html`):** Outlines event packages using an interactive comparison table and a breakdown of available add-ons.


* **Gallery Page (`gallery.html`):** Displays a categorized portfolio of past events using HTML media elements and structured figures.


* **Contact Us Page (`contact.html`):** Houses direct contact details and an inquiry form.


* **Client Portal / Login Page (`login.html`):** Provides account access for returning clients to track bookings, along with a registration form for new clients.



---

## 4. Design and User Experience (UX)

* **Color Scheme:** Pink with a bluish tint, paired with accent purple.


* **Typography:** Clean sans-serif primary font hierarchy for optimal readability.


* **Layout:** Multi-page layout utilizing standard HTML5 semantic tags (`header`, `nav`, `main`, `section`, `figure`, `footer`).


* **UX Considerations:**
* Top navigation bar present on every page for intuitive site flow.


* High contrast text to ensure accessibility compliance.


* Standardized form input labeling.


* Organized visual sections separated by horizontal dividers.




* **Wireframing:** Structural layout establishing clear hierarchy, placing branding and navigation at the top, primary content and forms in the central viewport, and copyright with contact details in the footer.
